JellyBoost

Desktop browsers apply the boost instantly with Web Audio. TVs, phones, Jellyfin Media Player and other native apps get it from the server, which re-encodes only the audio track (video is still copied). Users change their own level from the volume boost button in the web player; it follows their account to every device.

Required for TV and native apps. Boosted users get an audio-only transcode instead of direct play.
Reload the web client after changing this.
+6 dB is about twice as loud, +12 dB about four times. A limiter prevents clipping.

Per-user boost

Useful for accounts that only watch on TV. Leave a user blank to use the defaults above.
